# KIDE Demonstrator Quickstart

1. Install Eclipse Modeling Tools (2023-12 or newer) with Xtext support.
2. Import all repository folders as existing projects.
3. Build workspace once (`Project -> Build All`).
4. Open `com.mncml/representations.aird` or `com.model.domain.activity.design/representations.aird` in Sirius.
5. Use DSL editors from:
   - `com.mncml.dsl` (MNC DSL)
   - `com.smr.activity.dsl` (Activity DSL)

This package was generated by `scripts/build_demo_product.py`.
